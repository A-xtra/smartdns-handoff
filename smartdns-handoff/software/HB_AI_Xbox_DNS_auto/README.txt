HB AI · Smart DNS 1.22 авто — форк HB_AI_Xbox_DNS 1.22 (github.com/neiroseti-ai/hb-ai-xbox-dns, MIT)

Запуск: HB_AI_Xbox_DNS_auto.exe (попросит права администратора). Перед запуском закройте оригинальный HB_AI_Xbox_DNS и DNS_tray.bat, выключите WARP/VPN.

Что изменено:
1. При включении DNS или смене сервиса адреса серверов скачиваются заново:
   GitHub HB AI (адреса автора) -> сохранённые с прошлого раза -> сайт сервиса (magicdns.ru, dns.quic.best) -> встроенные.
   Все варианты сразу проверяются (DNS для gemini.google.com + открытие Gemini), берётся рабочий; при равенстве — адреса HB AI.
   Таймеров и фоновых повторов нет: только по нажатию. «Найти лучший» тоже сначала обновляет адреса.
   Выбранные адреса сохраняются в C:\ProgramData\HB AI Smart DNS\servers.txt.
2. При закрытии программы (крестик) и при выключении Windows DNS возвращается к обычному (от роутера), IPv6 включается обратно.
   Чтобы DNS оставался включённым — сворачивайте окно, а не закрывайте.

Сборка из исходников (вместо готового exe): src\build.bat -> src\HB_AI_Xbox_DNS_auto.exe (нужен только .NET Framework 4, есть в Windows 10/11).
